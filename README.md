I am a Cloud Reliability Engineer with a passion for empowering developers
through automation. In my free time I build games and web apps in Go and Deno,
deployed to Google Cloud Run, all managed through infrastructure-as-code.

## Repositories

### [Vex](https://github.com/dmikalova/vex)

A rules engine for a [KeyForge](https://keyforge.fandom.com/)-style card game,
written in Go, with a WebAssembly client for playing in the browser. It models a
full two-player match, including houses, Æmber, keys, combat and card abilities,
and implements more than a thousand cards. Playable at
[vex.mklv.tech](https://vex.mklv.tech).

### [keyforge.cards](https://github.com/dmikalova/keyforge.cards)

Landing pages for [keyforge.cards](https://keyforge.cards) and its KeyForge
tools: the Amasser browser extension and a bingo board generator.

### [Infrastructure](https://github.com/dmikalova/infrastructure)

Terramate stacks with OpenTofu for managing personal infrastructure. Includes
GCP resources, GitHub repository configuration, and Supabase databases. Secrets
encrypted with SOPS and Age.

### [Tasks](https://github.com/dmikalova/tasks)

Personal task app with smart task selection and flexible recurrence, focused on
getting the right task done at the right time. Live at
[tasks.mklv.tech](https://tasks.mklv.tech).

### [Login](https://github.com/dmikalova/login)

Centralized authentication service for mklv.tech apps using Supabase Auth. Built
with Deno and Hono.

### [Diatom](https://github.com/dmikalova/diatom)

In design: an agent harness that runs coding agents continuously through a
priority queue while I review their commits hunk by hunk, streaming corrections
back in as new work.

### [Factorio Mods](https://github.com/dmikalova/factorio-mods)

Collection of small Factorio mods available on
[the Factorio mod portal](https://mods.factorio.com/user/dmikalova).

### [project-standards](https://github.com/dmikalova/project-standards)

The standards every project follows regardless of language: a Go-native
toolchain of shared checks with generated tool configs, one reusable CI/CD
workflow that checks, releases and deploys every project, and a weekly
conformance bot that keeps each project in line.

### [Dotfiles](https://github.com/dmikalova/dotfiles)

Personal configuration files managed with [Chezmoi](https://www.chezmoi.io/).
